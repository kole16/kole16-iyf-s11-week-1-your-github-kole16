# Accessibility Report

## Issues Found
- Missing `<main>` landmark in HTML
- Missing meta description
- Images missing width/height attributes or incorrect aspect ratio

## How I Fixed Them
- Added a `<main>` element to improve page structure
- Added a meta description inside the `<head>` section
- Added width and height attributes to images and corrected aspect ratio issues
- Ensured proper semantic HTML structure (`header`, `main`, `footer`)

- 100/100
